-   [ ] Understand O(n²)

# Final Revision Rule

Before considering a problem complete:

-   [ ] I understand the problem without looking at the solution.
-   [ ] I can explain the brute-force idea.
-   [ ] I can explain the optimized approach.
-   [ ] I can write the C++ code using `cin`.
-   [ ] I can dry-run the code.
-   [ ] I know the time complexity.
-   [ ] I know the auxiliary space complexity.
-   [ ] I can explain the solution verbally in an interview.
